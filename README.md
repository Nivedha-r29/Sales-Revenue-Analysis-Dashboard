# Sales & Revenue Analysis Dashboard

## Project Overview

This Power BI dashboard analyzes sales performance, revenue trends, product performance, and regional sales distribution using the Sample Superstore dataset.

## Key Features

* KPI Tracking (Sales, Profit, Orders, Quantity)
* Revenue Trend Analysis
* Sales by Category Analysis
* Top 10 Products by Sales
* Regional Sales Analysis
* Interactive Filters and Slicers

## Tools Used

* Power BI Desktop
* Microsoft Excel / CSV Dataset
* Data Visualization
* DAX Measures
